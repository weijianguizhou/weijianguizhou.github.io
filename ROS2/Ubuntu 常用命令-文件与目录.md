# Ubuntu 常用命令：文件与目录

## 打开终端

第一件事是学会打开终端。常用的终端打开方式无外乎两种：

- 使用快捷键 Ctrl+Alt+T
- 文件夹中右击打开 *open in Terminal*

## ls 命令

就是 list 的缩写，通过 ls 命令不仅可以查看 *linux* 文件夹包含的文件，而且可以查看文件权限(包括目录、文件夹、文件权限)，查看目录信息等等。

**ls 命令常用参数**

```bash
ls -a  列出目录所有文件，包含以.开始的隐藏文件
ls -A  列出除.及..的其它文件
ls -r  反序排列
ls -t  以文件修改时间排序
ls -S  以文件大小排序
ls -h  以易读大小显示
ls -l  列出文件的权限、所有者、文件大小等详细信息
```

实例：

**按易读方式按时间反序排序，并显示文件详细信息**

```bash
ls -lhrt
```

**按大小反序显示文件详细信息**

```bash
ls -lrS
```

**列出当前目录中所有以"t"开头的目录的详细内容**

```bash
ls -l t*
```

**列出文件绝对路径（不包含隐藏文件）**

```bash
ls | sed "s:^:`pwd`/:"
```

**列出文件绝对路径（包含隐藏文件）**

```bash
find $pwd -maxdepth 1 | xargs ls -ld
```

## cd 命令

**cd(changeDirectory) 命令语法：**

```bash
cd [目录名]
```

说明：切换当前目录至 dirName。

示例：

**进入要目录**

```bash
cd /
```

**进入 "home" 目录**

```bash
cd ~
```

**进入上一次工作路径**

```bash
cd -
```

**把上个命令的参数作为cd参数使用。**

```bash
cd !$
```

## pwd 命令

pwd 命令用于查看当前工作目录路径。它是初学者最常用来确认“我现在在哪”的命令。

**查看当前路径**

```bash
pwd
```

**查看软链接的实际路径**

```bash
pwd -P
```

## mkdir 命令

mkdir 命令用于创建文件夹。

**mkdir 常用参数**

```bash
mkdir -m    对新建目录设置存取权限
mkdir -p    若路径中某些目录尚不存在, 系统会自动建立(一次建多级)
```

实例：

**当前工作目录下创建名为 t 的文件夹**

```bash
mkdir t
```

**在 tmp 下创建 path test/t1/t, 若目录不存在则一并建立**

```bash
mkdir -p /tmp/test/t1/t
```

## rm 命令

删除一个或多个文件或目录。如果不加 *-r* 选项，rm 不会删除目录。删除文件通常仍可以恢复，但删除目录需谨慎。

**rm 常用参数**

```bash
rm -i    删除前逐一询问确认
rm -r    递归删除(连同子目录一起删除)
rm -f    强制删除, 不提示
```

实例：

**删除任何 .log 文件, 删除前逐一询问**

```bash
rm -i *.log
```

**删除 test 子目录及其中所有内容, 不一一确认**

```bash
rm -rf test
```

**删除以 - 开头的文件(用 -- 结束选项)**

```bash
rm -- -f*
```

## cp 命令

将源文件复制到目标文件，或将多个源文件复制到目标目录。

**cp 常用参数**

```bash
cp -i    目标文件已存在时提示是否覆盖
cp -r    复制目录及目录内所有内容
cp -a    保持原文件的时间等属性
cp -s    建立符号链接(快捷方式)
```

实例：

**复制 a.txt 到 test 目录, 保持时间, 存在则提示**

```bash
cp -ai a.txt test
```

**为 a.txt 建立一个链接(快捷方式)**

```bash
cp -s a.txt link_a.txt
```

## mv 命令

移动文件，或修改文件／目录名。当第二个参数是目录时，将第一个参数（可以是多个）移动到该目录。

**mv 常用参数**

```bash
mv -i    目标已存在时提示是否覆盖
```

实例：

**将文件 test.log 改名为 test1.txt**

```bash
mv test.log test1.txt
```

**把多个文件移动到根的 test3 目录**

```bash
mv log1.txt log2.txt log3.txt /test3
```

**移动当前目录下所有文件到上一级目录**

```bash
mv * ../
```

## cat 命令

cat 主要有三大功能：一次显示整个文件；从键盘创建一个新文件；将几个文件合并成一个文件。

**cat 常用参数**

```bash
cat -b    对非空输出行号
cat -n    输出所有行号
```

实例：

**一次显示整个文件**

```bash
cat filename
```

**从键盘创建一个文件(只能新建, 不能编辑已有文件)**

```bash
cat > filename
```

**把 log2012.log 内容加上行号后写进 log2013.log**

```bash
cat -n log2012.log log2013.log
```

**反向列示文件(与 cat 相反)**

```bash
tac log.txt
```

## more 命令

功能类似于 cat，但会一页一页显示，方便逐页阅读。按空格键往下翻一页，按 *b* 键往回翻一页，按 *q* 键退出。

**more 常用参数**

```bash
more +n    从第 n 行开始显示
more -n    定义屏幕大小为 n 行
more -s    把连续多个空行显示为一行
```

实例：

**显示文件中从第 3 行起的内容**

```bash
more +3 text.txt
```

**借助管道让 ls -l 每次只显示 5 行**

```bash
ls -l | more -5
```

## less 命令

less 与 more 类似，但使用 less 可以随意前后浏览文件，more 只能向前。而且 less 在查看之前不会加载整个文件，更适合大文件。

**less 常用操作**

```bash
/字符串    向下搜索字符串
?字符串    向上搜索字符串
n          重复前一个搜索
N          反向重复前一个搜索
空格        滚动一页
b          向后翻一页
-q         退出
```

实例：

**查看进程信息并通过 less 分页显示(带行号)**

```bash
ps -aux | less -N
```

**查看多个文件(按 n 下一个, p 前一个)**

```bash
less 1.log 2.log
```

## head 命令

显示文件的开头内容，默认显示前 10 行。

**head 常用参数**

```bash
head -n <行数>    显示的行数
head -c <字节数>  显示前多少个字节
```

实例：

**显示 1.log 文件中前 20 行**

```bash
head 1.log -n 20
```

**显示最后 10 行(行数为负数表示从后往前数)**

```bash
head -n -10 t.log
```

## tail 命令

显示文件末尾内容，常用来查看日志文件。

**tail 常用参数**

```bash
tail -f    循环读取(适合查看动态增加的日志)
tail -n <行数>  显示行数(从后往前)
```

实例：

**循环读取逐渐增加的文件内容**

```bash
tail -f ping.log
```

## which、whereis、locate、find 命令

这四个命令都能用来找文件，但原理和适用场景各不相同：

- **which** 在 PATH 中查找可执行命令的位置，返回第一个匹配结果。
- **whereis** 只搜索程序名相关的二进制、帮助和源码文件，速度快。
- **locate** 基于系统数据库查找文件，速度很快，但新建文件可能找不到。
- **find** 实际遍历硬盘查找文件，最准确但最慢。

实例：

**查看 ls 命令是否存在及其位置**

```bash
which ls
```

**查找 locate 程序的相关文件**

```bash
whereis locate
```

**查找与 pwd 相关的所有文件**

```bash
locate pwd
```

**在当前目录查找以 .log 结尾的文件**

```bash
find ./ -name '*.log'
```

**查找 /opt 目录下权限为 777 的文件**

```bash
find /opt -perm 777
```

**查找更改时间在 10 日以前的文件并删除(无提示)**

```bash
find . -type f -mtime +10 -exec rm -f {} \;
```
