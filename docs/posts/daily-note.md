# 日常随笔

不定时更新我的日常想法……

## 2026-10-26

今天是周一，教授《工程流体力学》这门课的王成跃老师邀请了他的导师，刚刚评上中国科学院院士的王晋军教授来为我们做学术讲座，讲的是三维变形测量技术。

学术汇报固然有收获，但真正的收获来自于学术汇报之后，和教授《弹性力学》的尹晓春老师的一番交流。

讲座让原本上两小节的《弹性力学》只剩下了一小节，那仅剩的一小节上课之前，尹老师问我，你听懂了吗？

我说，我没听懂，因为我不懂光学，听不懂他的原理。

他说，那你听了什么？

我说，他介绍了一种用来测量机翼振动的技术。

他说，怎么实现的？

我说，用的相干光还有多普勒效应。

他问，为什么要有这个技术？

……

……

如此几轮，他说，你其实听懂了。

我说，我没听懂。

他说，站在你的角度你没听懂，因为你试着站得很远去看一棵树上的叶子，然后想从叶子看到整个树。

我惊愕，为什么这么说？

他说，听学术汇报应该是看山水画，一是看全貌——为什么要研究这个，二是用的研究方法是什么，三是怎么实现，四是用了什么思想，最后才是你最关心的原理，但最后一部分最不重要，因为你随时随地都能找到。

是树，是画，是一条崭新的路。

名师大抵如此。
