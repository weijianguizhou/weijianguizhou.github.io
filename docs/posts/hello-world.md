# 你好，世界

这是第一篇文章，也是这个站点搭好之后最该删掉的一篇——它的作用是让你看到「一篇文章长什么样」。

## 为什么要有这个博客

把学过的东西写下来，有三个好处：

1. **逼自己想清楚**。能讲明白，才算真懂。
2. **攒作品**。几年后回头看，这些文章就是你的履历。
3. **减少重复解释**。下次有人问同样的问题，发链接就行。

## 下一篇写什么

想到什么写什么，先把「持续写」这件事跑起来，再谈质量。

::: tip 一个建议
给自己定个低到不可能失败的目标：**每周 200 字**。写不满 200 字也算完成，重点是别断。
:::
