# 一些涩话

爱吃烧饼的大熊猫，南京理工大学本科生，力学与机器人方向。

余性鲁钝，记诵尤拙。少时读书，旋读旋忘，每至师前不能答，退而自愧。及长，稍知力学、机器人之为学，然皆浅尝，未有一得。

昔宋濂作《送东阳马生序》，自言家贫无书，假借于人，手自笔录，天大寒而弗之怠；又负箧曳屣，行深山巨谷中，以求解惑。余读而愧焉：今有网络，典籍唾手可得，不必借书，不必手抄，而余之勤，去宋氏远甚，此非时之咎，乃己之惰也。

余之所记，不过抄撮讲师所言、摘录诸书之要，非有创见；偶有一二会心处，方自喜而旋知其浅陋。所以录之者，非敢云著述，聊以备遗忘，并求教于同学之人耳。

至于力学之难、机器人仿真与实机之隔，余方摸索，未得其门。然愿以钝拙之资，日进一步，不务速成，但求不欺。他日或有所得，当更录之；其有误者，亦当自改。
