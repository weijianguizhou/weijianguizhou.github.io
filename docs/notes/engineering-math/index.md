## 说明

想记录一下以后学习科研中会经常碰到的数学知识。

就想着不那么严密了。因为我的数学分析学的不是很好。知道什么情况下能用就行。

本笔记整理自课堂讲授与参考教材，内容覆盖复变函数、级数、留数、积分变换与场论等核心章节。记号约定见绪论中的符号说明。

本书采用如下记号约定：

| 符号                   | 含义                 |
|:-----------------------|:---------------------|
| $z$                  | 复数，$z = x + iy$ |
| $\Arg z$             | 辐角主值             |
| $\arg z$             | 辐角                 |
| $|z|$                | 复数的模             |
| $\bar{z}$            | 共轭复数             |
| $e^z$,  $\ln z$    | 指数函数 / 对数函数  |
| $\oint$,  $\oiint$ | 回路积分 / 面积分    |
| $\mathcal{F}$        | Fourier 变换         |
| $\mathcal{L}$        | Laplace 变换         |
| $\mathcal{Z}$        | $Z$ 变换           |
