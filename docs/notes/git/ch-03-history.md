# 第三章 版本回溯与远程同步

## 版本回溯与远程同步

### 1. 查看所有历史版本

```bash
git log
```

作用：查看所有提交记录、版本号、修改时间，用于回退版本。

### 2. 代码改错，回退到历史版本（救急）

```bash
git reset --hard 你的版本号
```

作用：**强制还原**到指定版本，当前所有改动清空（谨慎使用）。

### 3. 本地代码乱了，用远程仓库覆盖本地

```bash
git fetch --all && git reset --hard origin/master
```
