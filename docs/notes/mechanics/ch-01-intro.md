# 第一章 绪论

## 1.1 符号说明

本书采用如下记号约定：

*表 1.1　符号说明*

| 符号 | 含义 |
| :---: | :--- |
| $\sigma$ | 正应力 |
| $\tau$ | 切应力 |
| $\varepsilon$ | 正应变 |
| $\gamma$ | 切应变 |
| $E$ | 弹性模量 |
| $G$ | 切变模量 |
| $\nu$ | 泊松比 |
| $F_N$ | 轴力 |
| $M$ | 弯矩 |
| $T$ | 扭矩 |
| $F_S$ | 剪力 |
| $I_z$ | 截面对 $z$ 轴的惯性矩 |
| $W_z$ | 抗弯截面系数 |
| $\lambda$ | 柔度 |
