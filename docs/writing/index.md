# 写作与排版

我对「把文字排好看」这件事的兴趣，其实是被逼出来的：课程报告要交 PDF，公式一多 Word 就开始乱；课堂笔记越记越长，回头找一句话要翻半天。于是从 LaTeX 开始，一路摸到 Markdown，最近又试了试 Typst。

这里收的是三份使用记录。不是教程，也不是「从入门到精通」——更像是我自己学习过程的流水账：哪天装环境装到半夜、哪条命令试了三次才对、最后哪套工具留在了电脑里。写下来主要是为了以后忘了命令时能翻，也顺手给来问的同学省点事。

## 三套工具，各管一段

| 对比 | LaTeX | Markdown | Typst |
| --- | --- | --- | --- |
| 上手成本 | 高，要装发行版、配编辑器 | 很低，有记事本就能写 | 低，语法接近 Markdown |
| 公式 | 最强，出版级 | 够用，`$...$` 与 LaTeX 同源 | 够用，写法更短 |
| 长文档 | 目录、编号、交叉引用、文献全自动 | 靠编辑器或插件 | 原生支持 |
| 实时预览 | 一般（要编译） | 编辑器里基本是即时的 | 快，边写边显示 |
| 我拿它写 | 论文、课程报告、讲义 | 博客、课堂笔记、随手记 | 还在试 |

## 一点个人结论

工具没有绝对的好坏，只有「现在手头这件事」合不合适：

- 要交给老师、要打印、公式和交叉引用多——**LaTeX**，慢一点但结果稳；
- 记笔记、写博客、发消息——**Markdown**，想到什么写什么，不被格式打断；
- 想要 Markdown 的轻快、又想要 LaTeX 的排版——**Typst** 值得一试，至少我是这么入坑的。
