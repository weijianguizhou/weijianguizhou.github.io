# Typst 初体验

LaTeX 用顺手之后，我对「换工具」这件事其实挺懒的。直到不止一次刷到 Typst，说它标记语法接近 Markdown、编辑时实时预览、编译又快，才决定花一个晚上，照着官方教程从头走一遍。

这篇就是那晚的记录。不是教程搬运，更像是我一边点、一边试、一边想「这个和 LaTeX 有什么不一样」的过程。

## 一、第一印象：标记比 LaTeX 轻

Typst 的思路和 LaTeX、Markdown 都不完全一样：**最常见的内容用标记写，其它一切交给函数**。标题、列表、强调这些天天用的东西，都有专门的符号；插入图片、生成图表这种「偶尔用一次」的，才调用函数。

教程从写下第一行文字开始。输入的文字会立刻显示在右侧预览里，不用等编译——这一点和 Obsidian 的实时预览很像，对改稿特别友好。

## 二、标题、强调和列表

- 标题：一个 `=` 就是一级标题，`==` 是二级标题，等号的数量决定嵌套层级；
- 强调：用下划线把文字包起来，比如 `_冰川_` 显示为斜体；
- 段落：两段文字之间空一行就是新段落；
- 列表：`+` 开头是编号列表，`-` 开头是无序列表，缩进一下就能嵌套子列表。

照着教程，我写了一份「影响冰川运动的因素」：

```typst
= 在_Typst_上写作

那我们就从撰写引言开始吧。在编辑框中输入一些文字吧。

== 影响冰川运动的因素

+ The climate
  - Temperature
  - Precipitation
+ The topography
+ The geology
```

和 LaTeX 的 `\section{}`、`\begin{itemize}` 相比，符号少了很多，写的时候脑子不用一直想着「环境有没有闭合」。代价是遇到复杂结构时还是得查函数怎么调用，只是这些结构出现的频率不高。

## 三、图片和图表

Typst 支持 PNG、JPEG、GIF、SVG、PDF 和 WebP 格式的图片。插入图片要用 `image` 函数，再套一层 `figure` 给它编号和图注：

```typst
#figure(
  image("glacier.png", width: 70%),
  caption: [
    _Glaciers_ form an important part
    of the earth's climate system.
  ],
)<glaciers>
```

<Figure src="/writing/typst-glacier.webp" alt="冰川" caption="图 1　教程里的示例图片：冰川" :width="360" />

最后尖括号里的 `<glaciers>` 是这个图表的标签，正文里可以用 `@glaciers` 引用它，和 LaTeX 的 `\label` / `\ref` 是一个意思，只是写起来短得多。教程里的例句就是：

```typst
We follow the glacier melting models
established in @glaciers.
```

## 四、数学公式

Typst 内置数学排版，但用的是它自己的一套符号，不直接吃 LaTeX 语法。行内公式用 `$` 包起来：

```typst
The equation $Q = rho A v + C$ defines the glacial flow rate.
```

如果想让公式单独占一行，就在开头和结尾的 `$` 两侧各加一个空格。比如：

```typst
$ Q = rho A v + C $
```

哪儿不一样呢？LaTeX 里写 `\rho`，Typst 里直接写 `rho`；希腊字母、运算符的输入方式都要重新记一遍。我试着把之前笔记里的公式复制过来，果然报错了。LaTeX 公式不能直接搬进 Typst，得按它的符号表改。

::: tip 给想试的人
换工具之前先想清楚：如果手头有大量现成的 LaTeX 公式和模板，迁移成本可能比想象中高；如果是从零开始写一份新文档，Typst 的轻快会很有吸引力。
:::

## 五、和 LaTeX 比，我的初步感受

**让我喜欢的地方**：

- 实时预览，写完一段立刻看到结果，不用反复编译；
- 常见结构不用写环境，标题、列表几行符号就够了；
- 语法接近 Markdown，学过 Markdown 的话上手很快。

**还拿不准的地方**：

- 模板和生态：期刊、学校的现成模板，Typst 这边远没有 LaTeX 多；
- 参考文献样式、复杂表格这些「长文档刚需」，教程只讲了个开头，我还没真正用过；
- 中文排版细节（字体、断行、标点挤压）也还没细看。

所以现阶段的结论很保守：**短报告、讲义、随手排版，我愿意再试试 Typst；论文和课程报告，还是先留在 LaTeX 里**。等哪天拿一门课的笔记完整迁过去跑一遍，再回来更新这一篇。

## 六、小结

试完之后，我对这三个工具的分工反而更清楚了：

- **Markdown** 负责「快」：课堂笔记、博客、随手记；
- **Typst** 负责「轻」：想排得好看、又不想背 LaTeX 命令的时候；
- **LaTeX** 负责「稳」：正式论文、长报告、需要模板和交叉引用的场合。

这一晚没让我弃用 LaTeX，但至少下次要排一份短报告时，我会先打开 Typst 试十分钟。工具合不合手，还是得写一篇自己的东西才知道。
