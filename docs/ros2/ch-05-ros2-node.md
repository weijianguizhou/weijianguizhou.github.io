# 第五章 · ROS 2 节点

## 5.1 背景

### ROS 2 图

ROS 图是一个由 ROS 2 元素组成的网络，这些元素同时处理数据。它包含了所有可执行文件以及它们之间的所有连接（如果将它们全部绘制出来并可视化的话）。

![ROS 2 图](/ros2/nodes-topics-services.webp)

一个完整的机器人系统由许多协同工作的节点组成。在 ROS 2 中，一个可执行文件（C++ 程序、Python 程序等）可以包含一个或多个节点。

### ROS 2 节点列表

`ros2 node list` 将显示所有正在运行的节点的名称。当想要与某个节点交互，或者系统运行着许多节点并需要跟踪它们时，此功能尤其有用。

在 TurtleSim 仍在运行的情况下，打开一个新的终端，并输入 `ros2 node list`。终端将返回节点名称。

效果如下图：

![ROS 2 节点列表](/ros2/node-list.webp)

## 5.2 重映射

重新映射允许我们将默认节点属性（例如节点名称、主题名称、服务名称等）重新分配给自定义值。
