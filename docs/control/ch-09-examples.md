# 附录 A 典型例题讲解

本讲（课件「第 22 讲·典型例题讲解」）覆盖五类常考题：物理系统建模、方框图化简、稳定范围与稳态误差、根轨迹、Nyquist 判稳。下面只保留题目要点与解题主线。

## 例 1　由物理系统求传递函数

同一道题给出两个相似系统：**(A) 机械平移系统**、**(B) 无源电路网络**。

**(A) 机械系统**：质量 $m$ 由输入位移 $x_i$ 经阻尼 $D_1$ 驱动，输出为其位移 $x_o$；质量又经弹簧 $k$ 与阻尼 $D_2$ 连到固定基座。对质量块列牛顿方程：

$$
m\ddot{x}_o = D_1(\dot{x}_i - \dot{x}_o) - D_2\dot{x}_o - k x_o
$$

拉氏变换（零初值）后整理：

$$
G_A(s) = \frac{X_o(s)}{X_i(s)} = \frac{D_1 s}{m s^2 + (D_1 + D_2)s + k}
$$

**(B) 电路网络**：$R$ 与并联的 $L$、$C$ 串联，输出取自并联端。用复阻抗与分压：

$$
G_B(s) = \frac{U_o(s)}{U_i(s)} = \frac{L s}{R L C s^2 + L s + 1}
$$

::: remark

两式结构完全一致：力—电压、速度—电流、质量—电感、阻尼—电阻、弹簧—电容的倒数。这正是机电系统相似的基础，建模只需算一次。

:::

## 例 2　方框图化简（梅逊公式）

方框图含两条前向通道与两个反馈回路（$G_3$ 为前馈、$H_2$ 为内环、$H_1$ 为外环），要求 $C(s)/R(s)$。画成信号流图后按梅逊公式逐项清点：

- 前向通道：$P_1 = G_1 G_2$，$P_2 = G_3 G_2$；
- 回路：$L_1 = -G_2 H_2$，$L_2 = -G_1 G_2 H_1$；两回路互相接触，且都与两条前向通道接触，故 $\Delta_1 = \Delta_2 = 1$；
- 特征式：$\Delta = 1 - (L_1 + L_2) = 1 + G_2 H_2 + G_1 G_2 H_1$。

于是

$$
\frac{C(s)}{R(s)} = \frac{1}{\Delta}(P_1 + P_2) = \frac{G_1 G_2 + G_3 G_2}{1 + G_2 H_2 + G_1 G_2 H_1}
$$

::: remark

化简框图有两条路：一是逐点等效移动（比较点/引出点前后移），二是画信号流图套梅逊公式。回路多、交叉多时后者更稳，关键是「找准回路、判断接触」。

:::

## 例 3　稳定范围与稳态误差

单位反馈系统开环 $G(s) = K(s+1)/s^2(s+10)^2$，求闭环稳定时 $K$ 的范围，以及 $r(t) = t^2/2$ 下的最小稳态误差。

闭环特征多项式：

$$
D(s) = s^2(s+10)^2 + K(s+1) = s^4 + 20 s^3 + 100 s^2 + K s + K
$$

列 Routh 阵列：

|  | $s^4$ | $1$ | $100$ |
| --- | --- | --- | --- |
|  | $s^3$ | $20$ | $K$ |
|  | $s^2$ | $(2000 - K)/20$ | $K$ |
|  | $s^1$ | $(1600 K - K^2)/(2000 - K)$ |  |
|  | $s^0$ | $K$ |  |

首列各项为正：

$$
K > 0,\quad 2000 - K > 0,\quad 1600 K - K^2 > 0 \quad\Rightarrow\quad 0 < K < 1600
$$

误差：$E(s)/R(s) = 1/(1+G)$，$R(s) = 1/s^3$，由终值定理

$$
e_{ss} = \lim_{s \to 0} s E(s) = \lim_{s \to 0} \frac{s^2(s+10)^2}{s^2(s+10)^2 + K(s+1)} \cdot \frac{1}{s^2} = \frac{100}{K}
$$

$K$ 取稳定上限 $1600$ 时误差最小：

$$
e_{ss,\min} = \frac{100}{1600} = 0.0625
$$

## 例 4　根轨迹分析与参数确定

反馈系统开环 $G(s)H(s) = K^*/[s(s+a)(s^2 + 2 s + 2)]$。

### 情形一：a = 3

开环极点 $0, -3, -1 \pm \mathrm{j}$，无开环零点。按法则：

- 实轴上的根轨迹：$[-3, 0]$；
- 渐近线：$\sigma_a = \frac{0 - 3 - 1 - 1}{4} = -1.25$，倾角 $\pm 45^\circ, \pm 135^\circ$；
- 分离点由 $1/d + 1/(d+3) + 1/(d+1+\mathrm{j}) + 1/(d+1-\mathrm{j}) = 0$ 化简得

$$
d^3 + 13 d^2 + 25 d + 15 = 0 \quad\Rightarrow\quad d = -0.8865
$$

（另两根 $-2.59$、$-6.52$ 不在根轨迹上，舍去。）

**求 $\zeta = 0.5$ 时的闭环传递函数**：在 $s$ 平面作 $\zeta = 0.5$（与负实轴成 $60^\circ$）的等阻尼线，与根轨迹的交点即主导极点。数值求解得

$$
K^* \approx 2.62,\quad s_{1,2} = -0.409 \pm 0.709\mathrm{j},\quad s_{3,4} = -2.77,\ -1.41
$$

$$
\Phi(s) = \frac{2.617}{s^4 + 5 s^3 + 8 s^2 + 6 s + 2.617}
$$

### 情形二：a = 2

$$
D(s) = s(s+2)(s^2 + 2s + 2) + K^* = s^4 + 4 s^3 + 6 s^2 + 4 s + K^*
$$

配方即见结构：

$$
D(s) = (s+1)^4 + (K^* - 1)
$$

- $K^* = 1$ 时 $D(s) = (s+1)^4$：四个极点全为实数且重根在 $s = -1$，输出无振荡分量；
- $K^* > 1$ 时出现一对共轭复根，响应开始振荡。

故所求闭环传递函数为

$$
\Phi(s) = \frac{1}{(s+1)^4}
$$

## 例 5　由 Nyquist 图判断闭环稳定性

$G(s)H(s) = 10/[s(s+1)(10 s + 1)]$，开环无右极点（$p = 0$）。

- 低频段：$\omega \to 0$ 时幅值趋于无穷、相角约 $-90^\circ$，曲线沿负虚轴向下；
- 与负实轴的交点：令 $\angle G = -90^\circ - \arctan \omega - \arctan 10 \omega = -180^\circ$，得 $\omega = 1/\sqrt{10} \approx 0.316$；
- 此时

$$
|G(\mathrm{j}\omega)| = \frac{10}{\omega\sqrt{1+\omega^2}\sqrt{1+100\omega^2}} \approx 9.09 > 1
$$

所以曲线在 $(-1, \mathrm{j}0)$ 左侧穿过负实轴，即包围 $(-1, \mathrm{j}0)$。而 $p = 0$，故闭环**不稳定**。

<Figure src="/control/ex-nyquist.webp" alt="Nyquist 图例题" caption="图 A.2　10/[s(s+1)(10s+1)] 的 Nyquist 图：与负实轴交于 -9.09，把 (-1, j0) 围在里面" :width="460" />

::: remark

同一结论用 Bode 图看更直观：$L(\omega) > 0$ 的频段内，相频曲线对 $-180^\circ$ 线发生一次正穿越，而 $p = 0$，正负穿越之差不为零，故闭环不稳定。

:::

::: tip 本章要点

- 建模题先列物理方程（牛顿/基尔霍夫），再做拉氏变换整理成「首一式」；机电系统可类比记忆。
- 框图化简：回路少用等效移动，回路多用梅逊公式；关键是数清前向通道与回路、判断是否接触。
- 稳定范围用 Routh 首列定号；稳态误差用终值定理，注意输入阶次与系统型别。
- 根轨迹题：实轴段、渐近线、分离点、等阻尼线四步走；参数确定后反写闭环传递函数。
- Nyquist 判稳：先数开环右极点 $p$，再看曲线是否包围 $(-1, \mathrm{j}0)$，两者对照下结论。

:::
