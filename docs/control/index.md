# 控制工程基础

古典控制理论（经典控制理论）的课程笔记：以传递函数为主线，从建模、时域响应、频率特性，到稳定性、稳态误差、校正与根轨迹。笔记按董景新等《控制工程基础》的课程顺序整理，语言从简、推导从略，保留结论、方法与图形。

| [第二章 控制系统的动态数学模型](/control/ch-02-model.html) | 机理建模、线性化、拉氏变换、传递函数与典型环节、方块图、梅逊公式 |
| [第三章 时域瞬态响应分析](/control/ch-03-time-response.html) | 一阶与二阶系统响应、超调量、调整时间等性能指标 |
| [第四章 控制系统的频率特性](/control/ch-04-frequency.html) | 频率特性、Nyquist 图、Bode 图、开环与闭环频域指标 |

## 怎么读

前两章是地基：先把「微分方程 → 传递函数 → 方块图」这条线走通，后面的时域、频域、根轨迹都只是从不同角度看同一个传递函数。

- 只想应付考试：第三章的性能指标公式、第五章的三个判据、第六章的稳态误差表、第八章的绘制规则是重点；
- 想真的会用：第二章的建模与方块图化简、第七章的校正设计要动手算几遍，例题附录可以对照着做。
