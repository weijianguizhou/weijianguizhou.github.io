# 第八章 根轨迹法

**根轨迹法**：由开环传递函数求闭环特征根的图解方法。特点：直观形象；适合研究某一参数变化时系统性能的变化趋势；是近似方法。

## 根轨迹与根轨迹方程

::: definition 根轨迹

当系统某一参数（通常是根轨迹增益 $K^*$）由 $0$ 变化到 $+\infty$ 时，闭环特征根在 $s$ 平面上相应变化所描绘出的轨迹，称为**根轨迹**。

:::

::: example

单位反馈系统 $G(s) = K^*/(s(s+2))$，闭环特征方程 $s^2 + 2s + K^* = 0$，根为 $\lambda_{1,2} = -1 \pm \sqrt{1 - K^*}$。$0 < K^* < 1$ 时为两个负实根，$K^* = 1$ 时为重根 $-1$，$K^* > 1$ 时为一对共轭复根，实部恒为 $-1$——根轨迹是实轴上的 $[-2, 0]$ 段以及直线 $\sigma = -1$。

:::

闭环特征方程 $1 + G(s)H(s) = 0$，即

$$
G(s)H(s) = -1
$$

写成模值与相角两个条件（$G(s)H(s) = K^* \frac{\prod (s - z_i)}{\prod (s - p_j)}$）：

$$
\text{模值条件：}\ K^* = \frac{\prod_{j=1}^{n} |s - p_j|}{\prod_{i=1}^{m} |s - z_i|}, \quad\quad \text{相角条件：}\ \sum_{i=1}^{m} \angle(s - z_i) - \sum_{j=1}^{n} \angle(s - p_j) = (2k + 1)180^\circ
$$

**相角条件是 $s$ 点位于根轨迹上的充要条件**；满足相角条件后，对应的 $K^*$ 由模值条件唯一确定。注意根轨迹增益 $K^*$ 与开环增益 $K$ 不同（二者相差一个常数因子）。

## 绘制根轨迹的基本法则

1. **起点与终点**：起于开环极点（$K^* = 0$），终于开环零点（$K^* \to \infty$）；若 $n > m$，有 $n - m$ 条终于无穷远；
2. **分支数、对称性与连续性**：分支数等于开环极点数 $n$；根轨迹连续且对称于实轴；
3. **实轴上的根轨迹**：实轴上某区段右侧开环零、极点总数为奇数时，该区段是根轨迹；
4. **根之和**：$n - m \ge 2$ 时，$\sum \lambda_i = \sum (-p_j)$ 为常数，与 $K^*$ 无关；
5. **渐近线**：$n - m$ 条趋于无穷远的根轨迹，其渐近线与实轴交于 $\sigma_a$、夹角为 $\varphi_a$：

   $$
   \sigma_a = \frac{\sum_{j=1}^{n} p_j - \sum_{i=1}^{m} z_i}{n - m}, \quad\quad \varphi_a = \frac{(2k + 1)180^\circ}{n - m}
   $$

6. **分离点（会合点）** $d$ 满足

   $$
   \sum_{j=1}^{n} \frac{1}{d - p_j} = \sum_{i=1}^{m} \frac{1}{d - z_i} \quad\quad (\text{无零点时右端为 0})
   $$

7. **与虚轴交点**：由 Routh 判据临界稳定条件，或令 $s = \mathrm{j}\omega$ 代入特征方程求；
8. **出射角与入射角**：复极点 $p$ 处的出射角为

   $$
   \theta_p = 180^\circ + \sum_{i=1}^{m} \angle(p - z_i) - \sum_{j=1,\, j \neq p}^{n} \angle(p - p_j)
   $$

## 其他参数根轨迹

当研究 $K^*$ 以外的参数 $a$ 变化时，先将特征方程整理成

$$
1 + a \cdot G_1(s) H_1(s) = 0
$$

的形式，构造**等效开环传递函数** $a G_1 H_1$，再按基本法则绘制参数根轨迹。步骤与原根轨迹完全相同，只是增益换成了参数 $a$。

## 利用根轨迹分析系统性能

基本步骤：绘制根轨迹 $\to$ 依题意确定闭环极点位置 $\to$ 确定闭环零点 $\to$ 保留主导极点，估算系统性能。

**等阻尼比线**：$s$ 平面上满足 $\cos \beta = \zeta$ 的射线（$\beta$ 为射线与负实轴夹角）。给定 $\zeta$，作等阻尼比线与根轨迹相交，交点即闭环主导极点；再由模值条件求对应的 $K^*$。

<Figure src="/control/damping-line.webp" alt="等阻尼比线求极点" caption="图 8.2　由等阻尼比线 ζ = 0.5（β = 60°）确定闭环极点" :width="460" />

::: example

单位反馈系统 $G(s) = K^*/(s(s+3)(s^2+2s+2))$，开环极点 $0, -3, -1 \pm \mathrm{j}$，无零点。

1. 分支数 $4$；实轴根轨迹段 $[-3, 0]$；
2. 渐近线：$\sigma_a = (0 - 3 - 1 - 1)/4 = -1.25$，$\varphi_a = \pm 45^\circ, \pm 135^\circ$；
3. 分离点由 $1/d + 1/(d+3) + 1/(d+1-\mathrm{j}) + 1/(d+1+\mathrm{j}) = 0$ 解得 $d \approx -2.29$（另一根 $-0.73$ 不在根轨迹上，舍去）；
4. 与虚轴交点：特征方程 $s^4 + 5s^3 + 8s^2 + 6s + K^* = 0$，Routh 表令 $s^1$ 行为零得 $K^* = 8.16$，对应 $s = \pm \mathrm{j}1.1$；
5. 取 $\zeta = 0.5$：等阻尼比线与根轨迹交于 $s_{1,2} = -0.4 \pm \mathrm{j}0.7$，由模值条件 $K^* \approx 2.9$；另两个闭环实极点约 $-1.5$、$-2.7$。

于是闭环传递函数约为

$$
\Phi(s) = \frac{2.9}{(s^2 + 0.8s + 0.65)(s + 1.5)(s + 2.7)}
$$

主导极点为 $-0.4 \pm \mathrm{j}0.7$。

:::

::: tip 本章要点

根轨迹法是“由开环看闭环”的图解方法：相角条件决定轨迹形状，模值条件决定增益；八条法则把手工绘制简化为少数几个特征量（起终点、实轴段、渐近线、分离点、虚轴交点、出射角）。给定 $\zeta$ 由等阻尼比线定极点，是分析系统动态性能的常用手段。

:::
