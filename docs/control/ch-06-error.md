# 第六章 控制系统的误差分析和计算

## 误差和偏差的概念

::: definition 误差与偏差

**误差** $e(t)$：系统希望的输出量与实际输出量之差，$E(s) = X_{oi}(s) - X_o(s)$；其稳态分量称**稳态误差**，记作 $e_{ss}$。

**偏差** $\varepsilon(t)$：输入信号与反馈信号之差，$\varepsilon(s) = X_i(s) - Y(s)$。

:::

<Figure src="/control/error-block.webp" alt="误差与偏差框图" caption="图 6.1　误差与偏差" :width="520" />

系统的误差与偏差一般并不相同。设反馈通道无干扰、$H(s)$ 为常数，则希望输出 $X_{oi} = X_i/H$，故

$$
E(s) = \frac{X_i(s)}{H(s)} - X_o(s) = \frac{\varepsilon(s)}{H(s)}
$$

即求出稳态偏差后，除以 $H(0)$ 即得稳态误差；对**单位反馈系统**，偏差与误差相同，直接求稳态偏差即可。

## 输入引起的稳态误差

偏差传递函数与稳态偏差：

$$
\frac{\varepsilon(s)}{X_i(s)} = \frac{1}{1 + G(s)H(s)}, \quad\quad \varepsilon_{ss} = \lim_{s\to 0} s\varepsilon(s) = \lim_{s\to 0} \frac{s X_i(s)}{1 + G(s)H(s)}
$$

稳态误差 $e_{ss} = \varepsilon_{ss}/H(0)$，它取决于系统的结构参数与输入信号的性质。

对单位反馈系统，定义**静态误差系数**（$G_k(s) = G(s)H(s)$ 为开环传递函数）：

$$
K_p = \lim_{s\to 0} G_k(s), \quad\quad K_v = \lim_{s\to 0} s G_k(s), \quad\quad K_a = \lim_{s\to 0} s^2 G_k(s)
$$

分别为静态位置、速度、加速度误差系数。设开环传递函数为 $G_k(s) = \frac{K \prod_i (\tau_i s + 1)}{s^\lambda \prod_j (T_j s + 1)}$，$\lambda$ 为型次。

| 系统型次 | 单位阶跃 | 单位斜坡 | 单位加速度 |
| --- | --- | --- | --- |
| 0 型 | $\frac{1}{1 + K_p} = \frac{1}{1 + K}$ | $\infty$ | $\infty$ |
| I 型 | $0$ | $\frac{1}{K_v} = \frac{1}{K}$ | $\infty$ |
| II 型 | $0$ | $0$ | $\frac{1}{K_a} = \frac{1}{K}$ |

$K_p$、$K_v$、$K_a$ 与型次、开环增益的关系：0 型 $K_p = K$，$K_v = K_a = 0$；I 型 $K_p = \infty$，$K_v = K$，$K_a = 0$；II 型 $K_p = K_v = \infty$，$K_a = K$。

::: example

某单位反馈 I 型系统开环增益为 $K$：单位阶跃输入时 $e_{ss} = 0$；单位斜坡输入时 $e_{ss} = 1/K$；单位加速度输入时 $e_{ss} = \infty$。

:::

## 干扰引起的稳态误差

<Figure src="/control/disturbance-error.webp" alt="干扰误差框图" caption="图 6.2　干扰 N(s) 作用于两环节之间" :width="460" />

干扰引起的偏差与稳态误差：

$$
\varepsilon(s) = \frac{-G_2(s)H(s)}{1 + G_1(s)G_2(s)H(s)} N(s), \quad\quad e_{ss} = \frac{\varepsilon_{ss}}{H(0)}
$$

求稳态误差的注意事项：

1. 先判断系统稳定性——不稳定系统谈不上稳态误差；
2. 多个量同时作用时，利用叠加原理分别求出各自的偏差再相加。

::: remark

若干扰从反馈通道引入，则 $E(s)/N(s) = -\frac{H_2(s)}{1 + G(s)H(s)}$，稳态误差无法靠提高前向通道增益消除——**无法消除系统频带以内测量干扰带来的误差**。故反馈元件的精度对减小系统误差至关重要。

:::

## 减小系统误差的途径

1. **提高反馈通道精度**：反馈通道元部件精度要高，避免在反馈通道引入干扰；
2. **提高开环增益、提高系统型次**：可减小输入引起的稳态误差，但受稳定性限制；对干扰引起的误差，可在干扰点前加积分器并增大放大倍数；
3. **复合控制（顺馈补偿）**：当单靠增大增益或串入积分环节不能同时满足稳态精度与动态性能时，按干扰或按输入进行补偿。

<Figure src="/control/disturbance-comp.webp" alt="按干扰补偿框图" caption="图 6.3　按干扰补偿：G_n(s) 为补偿环节" :width="520" />

按干扰补偿时，令干扰到输出的传递函数分子为零：

$$
G_2(s) + G_n(s)G_1(s)G_2(s) = 0 \quad\Rightarrow\quad G_n(s) = -\frac{1}{G_1(s)}
$$

按输入补偿时，取 $G_r(s) = 1/G(s)$，使误差传递函数为零（理想情况下实现完全补偿）。

## 动态误差系数

稳态误差相同的系统，误差随时间的变化未必相同——误差随时间的变化称**动态误差**。对单位反馈系统，将误差传递函数在 $s = 0$ 邻域展开为泰勒级数（可用长除法）：

$$
\Phi_e(s) = \frac{1}{1 + G(s)} = C_0 + C_1 s + C_2 s^2 + \cdots
$$

$C_0$、$C_1$、$C_2$ 分别称**动态位置、速度、加速度误差系数**。由 $E(s) = \Phi_e(s) X_i(s)$ 反变换得

$$
e(t) = C_0 x_i(t) + C_1 \dot{x}_i(t) + C_2 \ddot{x}_i(t) + \cdots
$$

::: example

单位反馈系统 $G(s) = 10/(s(s+1))$，输入 $x_i(t) = a_0 + a_1 t + a_2 t^2$。由长除法

$$
\Phi_e(s) = \frac{s + s^2}{s^2 + s + 10} = 0.1s + 0.09s^2 - 0.019s^3 + \cdots
$$

故

$$
e(t) = 0.1\dot{x}_i + 0.09\ddot{x}_i - 0.019x_i''' + \cdots = 0.1(a_1 + 2a_2 t) + 0.09(2a_2) + \cdots
$$

只要 $a_2 \neq 0$，$t \to \infty$ 时 $e_{ss} \to \infty$。

:::

::: tip 本章要点

稳态误差由系统型次、开环增益与输入性质共同决定：型次越高、增益越大，跟踪能力越强；但增益过大会削弱稳定性。干扰误差还与干扰作用点有关，反馈通道干扰无法用前向增益消除；必要时采用顺馈补偿。动态误差系数则描述了误差的瞬态变化过程。

:::
