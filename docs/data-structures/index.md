# 数据结构

数据结构课程笔记。按“基本概念 → 线性结构 → 非线性结构 → 查找与排序”的顺序组织，正文以 C++ 和 Python 双语言实现，每章末尾附有课后习题解答。

::: tip 关于这份笔记
这一套内容由三份材料融合而成：教程正文负责系统讲解，原始笔记中的图示与补充说明已并入对应小节，课后作业按知识点拆进对应章节。全系列共 28 张配图，均放在相关概念出现的段落。
:::

## 学习路线

1. **基础**：第一章先把数据结构和算法分析的语言统一，后面每章都会用到复杂度推导。
2. **线性结构**：第二到第六章，重点比较顺序存储与链式存储在插入、删除、查找上的取舍。
3. **非线性结构**：第七、八章，树和图是递归与遍历的主战场。
4. **算法应用**：第九、十章，查找与排序把前面所有结构串起来。
